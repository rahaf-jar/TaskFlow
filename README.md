# TaskFlow

TaskFlow is a SaaS productivity management platform that helps companies manage employees, customers, subscriptions, and product usage.

## Project Purpose

This project demonstrates database design and SQL skills by creating a relational database for a fictional software company.

## Technologies

- MySQL
- SQL
- MySQL Workbench
- Git
- GitHub

## Main Areas

- Employee management
- Customer management
- Sales tracking
- Subscription analytics
- Product feature management
- Customer usage analysis
